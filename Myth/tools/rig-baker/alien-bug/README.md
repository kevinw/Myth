# Alien Bug

Four-legged animated creature by CDmir, downloaded from
[OpenGameArt](https://opengameart.org/content/alien-bug-animated).

License: CC0 1.0. The source archive contains the Blender scene, glTF binary,
and diffuse, normal, and roughness textures. Myth currently bakes the skeleton
and the `Idle`, `Run`, `Attack.000`, and `Attack.001` clips from `alien-bug.glb`.
